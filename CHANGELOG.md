# Changelog

## 3.1

- One click on a preset applies it. The Apply button is gone.
- New categories: CPVP (Totem Pop, Crystal Blast, Anchor Boom, Rainbow Anchor and more), Audio, Text Out, Watermarks.
- Beat Pumps are now Beat Shakes and carry a small shake.
- Shakes use S_Shake and Twitch together and add a mirrored Motion Tile so the frame edge never shows. Mega Hit rebuilt.
- Time Remap redone: kill ramps burst, dip into slow motion and ease back to normal speed. New Slow Into Kill and Build + Kill Ramp.
- Text: animations keep the size and opacity of your layer, ins start where the layer starts, outs end where it ends. Many new ins, loops, pans and Light Sweep.
- Text FX: coloured glows, neon, outline glow, gradients, plasma, flux, scanlines, bevel, Rainbow Scroll, Drop Shadow, 3D Text through Element. 3D Extrude rebuilt, Light Rays toned down.
- Blur Names is a square shape layer with mosaic at 64. New Blur Chat and Blur Scoreboard.
- New Light Blue and Pink grades. Less glow on the other grades and on Title Reveal.
- Fades are even from start to end. Keyframes show as normal eased keys.
- New Mix transition, a plain crossfade. Spin transitions zoom in less. New Glow Flicker and Light Sweep.
- Beat markers moved to Tools.
- New flicker shakes and flicker beat shakes.
- New text uses tighter line spacing. Text Light Sweep adds rays and a glow swell so it shows on white text.

## 3.0

First public version, under the new name CPVP Editing.

- New panel: header, category picker, scrollable preset list, one-line description, Apply, target and length controls, status line, help view.
- Plugin detection at startup with built-in fallbacks. Presets that need a missing plugin are marked in the list.
- Shakes rebuilt with real S_Shake values, zoom punches on the Transform effect and much more Twitch. Many new stacked beat, impact, zoom and warp shakes.
- New categories: Beat Pumps, Build-Up, Intros + Outros.
- Transitions redone: spins with a slow-fast-slow graph, zoom-through cuts, working whips, Blur Dip that returns to sharp, Prism Flash peaking on the cut. S_BlurMoCurves always wraps with Reflect.
- Every curve retimed: impacts hit on frame one with a long tail, transitions speed up into the cut and coast out.
- Text: new text is centered, white, clean style. Every text animation ends sharp and fully visible. New Rainbow Wave, Drop In, Blur In, Zoom Punch In, Glitch In.
- FX: new Blur Names. Lens Flare now uses S_LensFlare.
- Rainbow presets use hue keyframes that really animate.
- Time remap ramps no longer run past the end of the clip.
