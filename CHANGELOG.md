# Changelog

## 3.0

First public version, under the new name CPVP Editing.

- New panel: header, category picker, scrollable preset list, one-line description, Apply, target and length controls, status line, help view.
- Plugin detection at startup with built-in fallbacks. Presets that need a missing plugin are marked in the list.
- Shakes rebuilt with real S_Shake values, zoom punches on the Transform effect and much more Twitch. Many new stacked beat, impact, zoom and warp shakes.
- New categories: Beat Pumps, Build-Up, Intros + Outros.
- Transitions redone: spins with a slow-fast-slow graph, zoom-through cuts, working whips, Blur Dip that returns to sharp, Prism Flash peaking on the cut. S_BlurMoCurves always wraps with Reflect.
- Every curve retimed: impacts hit on frame one with a long tail, transitions speed up into the cut and coast out.
- Text: new text is centered, white, clean style. Every text animation ends sharp and fully visible. New Rainbow Wave, Drop In, Blur In, Zoom Punch In, Glitch In.
- FX: new Blur Names. Lens Flare now uses S_LensFlare.
- Rainbow presets use hue keyframes that really animate.
- Time remap ramps no longer run past the end of the clip.
